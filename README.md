# 婚活漫才

婚活で出会った2人の経緯を、手掛かりが出るたびに「お見合い」か「マッチングアプリ」か判定し直していく、反復推理型のしゃべくり漫才です。

## 台本

- [script.md](./script.md)

## 今回の構成方針

ミルクボーイ型のしゃべくり漫才です。演者は新郎（ボケ）と新郎の友人（ツッコミ）、想定客層は25〜35歳の参列者です。

### ミルクボーイの型から借りたもの

- **お題は最後まで一つ。** ツッコミは「マッチングアプリやないかい」と「ほなマッチングアプリと違うかぁ」を行き来するだけで、別の候補には移らない。
- **「違うかぁ」は理屈ではなく偏見。** ボケが「アプリにしては良すぎる特徴」を出すと、ツッコミは「アプリがそんな立派なわけない」とアプリをけなして否定する。
- **否定は二段。** 「〜なわけないもんね」→ ボケ「そうやねん」→ もっと大きい偏見 → 「ほな〜と違うやないか」で締める。
- **ボケは特徴を一つ出すだけ。** 「いや、俺も〜と思うてんけどな」「オカンが言うには、〜って言うねんな」「そうやねん」以外はほぼ喋らない。
- **あるあるは「ありそうでない」くらいの誇張。** 25〜35歳が「分かる」と思える範囲で少しだけ大げさにする。
- **終盤は短い往復で畳みかけ、「もう分からへんがな」→「オトンが言うには」で落とす。**

### 特徴の並び

1. 写真・いいね・メッセージ → やないかい
2. 名字で親が家まで分かる → 違うかぁ（アプリの名前は🌸一個）
3. 新着の女性に男性が集中する → やないかい（新規会員の賞味期限）
4. 40代でも前の日に緊張して寝られへん → 違うかぁ（アプリの人は同じ週に初回三件）
5. 医者がやたら多い → やないかい（アプリの医者は日本の医者より多い）
6. 年収・家族構成などを事前に把握 → 違うかぁ（プロフィールは全部盛ってある）
7. 梅田の適当な飲み屋 → やないかい
8. いきなり三時間喋った → 違うかぁ（アプリの初回は40分で急用が入る）
9. 「ログイン3日以内」が表示される → やないかい
10. 大阪と千葉で移動距離を公平に計算 → 違うかぁ（アプリは5km以内で検索）
11. スワイプ / 白い画面に「お見合い」 / 仲人アイコン → 短く往復して「もう分からへんがな」
12. オトンが言うには「相席屋ちゃうか？」→「いや、絶対ちゃうやろ！もうええわ」

新郎新婦の出会いの特徴は元の台本のものをすべてそのまま使っています。

## Note

ミルクボーイの漫才の型（構造と定番の言い回し）を借りていますが、ネタの中身はこの結婚式用のオリジナルです。

# 婚活漫才

婚活で出会った2人の経緯を、手掛かりが出るたびに「お見合い」か「マッチングアプリ」か判定し直していく、反復推理型のしゃべくり漫才です。

## 台本

- [script.md](./script.md)

## 今回の構成方針

同じ判定フォーマットを繰り返し、観客がルールを理解したところで材料を交互に反転させます。

1. 写真・いいね・メッセージ → マッチングアプリ
2. 家の名前まで分かる → お見合い
3. 新しく入った女性に男性が集中する → マッチングアプリ
4. 40代でも恋愛に初々しい → お見合い
5. 医者がやたら多い → マッチングアプリ
6. 梅田の飲み屋で初対面から3時間 → マッチングアプリ寄り
7. 遠距離で双方の中間地点を調整 → お見合い寄り
8. 年収・家族構成などを事前に把握 → お見合い
9. 「ログイン3日以内」が表示される → マッチングアプリ
10. 白背景・黒文字の画面を手掛かりに最終反転

### ルール

- 「お見合い」「マッチングアプリ」という判定語を口にするのはツッコミだけ。
- ボケは特徴だけを追加し、ツッコミが毎回判定と理由付けを担当する。
- 前半は判定理由を丁寧に説明し、後半ほど短く強くしてテンポを上げる。
- 同じ反復でも理由の比喩を毎回変え、単なる言い換えにならないようにする。
- 最後は「白背景・黒文字」と「スマホ操作」の両方を出して、二つの判定を衝突させる。

## Note

特定の芸人の台詞や決めフレーズを再現するのではなく、反復、二択推理、反転、エスカレーションという一般的な漫才構造を使ってオリジナルに再構成しています。

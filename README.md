# 婚活漫才

婚活で出会った2人の経緯を、手掛かりが出るたびに「お見合い」か「マッチングアプリ」か判定し直していく、反復推理型のしゃべくり漫才です。

## 台本

- [script.md](./script.md)

## 今回の構成方針

ミルクボーイ型（「オカンが名前を忘れた」→「〜やないかい」「ほな〜ちゃうかぁ」の往復→「オトンが言うには」で落とす）に寄せています。想定客層は25〜35歳の参列者です。

1. 写真・いいね・メッセージ → マッチングアプリやないかい
2. 名字で親が家まで分かる → ほなマッチングアプリちゃうかぁ
3. 新着の女性に男性が集中する → マッチングアプリやないかい
4. 40代でも恋愛に初々しい → ほなマッチングアプリちゃうかぁ
5. 医者がやたら多い → マッチングアプリやないかい
6. 年収・家族構成などを事前に把握 → ほなマッチングアプリちゃうかぁ（ここで候補がお見合いに移る）
7. 梅田の飲み屋で初対面から3時間 → ほなお見合いちゃうかぁ
8. 大阪と千葉の中間地点を調整 → お見合いやないかい
9. 「ログイン3日以内」が表示される → ほなお見合いちゃうかぁ
10. 白背景・黒文字の「お見合い」とスマホでスワイプが衝突
11. オトンが言うには → 祝福で一度締めてから、最後にもう一回ボケて「もうええわ」

### ルール

- ボケは毎回「オカンが言うには」で特徴だけを出し、判定はツッコミが担当する。
- ツッコミは「〜やないかい」で肯定するときも「ほな〜ちゃうかぁ」で否定するときも、偏見まじりの具体的な理屈を長めに語る。
- 「でもこれちょっと分からへんのやな」「何が分からへんのよ」を区切りに使い、観客がリズムを覚えられるようにする。
- 25〜35歳に通じる材料（いいね、足あと、新規会員バッジ、盛ったプロフィール、初回カフェ1時間、ホテルラウンジのお見合い）をツッコミの理屈に入れる。
- 新郎新婦の出会いの特徴（梅田の飲み屋で3時間、大阪と千葉の遠距離など）は元の台本のものをそのまま使い、答えは断定しない。

## Note

ミルクボーイの漫才の型（構造と定番の言い回し）を借りていますが、ネタの中身はこの結婚式用のオリジナルです。
